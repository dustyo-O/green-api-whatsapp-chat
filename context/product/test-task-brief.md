## Translation (EN)

**Test task for the position "Frontend Developer (React)"**

Build a user interface for sending and receiving messages in **MAX** (if you cannot do it for MAX, WhatsApp or Telegram is acceptable). Time: **5 days**.

**Requirements**

1. A UI for sending and receiving messages in MAX.
2. Use **GREEN-API** — https://green-api.com/max
3. Text messages only, both directions.
4. Use the look of https://web.max.ru/ as the UI prototype.
5. Keep the UI as simple as possible, minimal feature set.
6. Sending via `SendMessage` — https://green-api.com/v3/docs/api/sending/SendMessage/
7. Receiving via the HTTP API (notification polling) — https://green-api.com/v3/docs/api/receiving/technology-http-api/
8. Use **React**.

**Expected result**

- User opens the chat site and enters GREEN-API credentials (`idInstance`, `apiTokenInstance`).
- User enters a recipient phone number and creates a new chat.
- User types a text message and sends it to the recipient in MAX.
- Recipient replies in the MAX messenger.
- User sees the reply in the chat.

**Submission** — email hr@green-api.com, subject "Тестовое задание на должность - Фронтенд разработчик React":

1. Resume (PDF, with Telegram handle)
2. GitHub repository link
3. Link to local-run instructions
4. Link to a deployed service (desirable)
5. Link to screenshots / video demo (if any)

Also state preferred work format (remote / Khimki office / Astana office).
