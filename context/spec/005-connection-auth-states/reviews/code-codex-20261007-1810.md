### F1: Failed deletes can leave connection loss invisible indefinitely
- severity: major
- where: src/chat/receive-loop.ts:reachable / fail
- problem: If receiving succeeds but deleting repeatedly fails at the network level, neither the offline nor stuck banner appears. Sending remains enabled.
- evidence: Each received notification calls `reachable()`, resetting `networkFailures` to zero; the subsequent failed delete only increments it to one. Network failures never start the stuck timer.
- fix: Preserve the delete failure streak across repeated receives of the undeleted notification, and test repeated successful receives followed by network-failed deletes.

### F2: Connection detection exceeds 20 seconds during deletion
- severity: major
- where: src/chat/receive-loop.ts:DELETE_BUDGET_MS / OFFLINE_AFTER
- problem: An upstream outage starting during deletion can exceed functional §2.2’s 20-second detection limit.
- evidence: A stalled delete takes 15 seconds, followed by 1 second of backoff and an 8-second receive timeout: approximately 24 seconds before the second network failure raises the banner. The deadline test covers only stalled receives.
- fix: Bound detection across both receive and delete phases to 20 seconds, and add an outage-during-delete test.

### F3: Confirmed-valid credentials can leave persistent receiving failures unreported
- severity: major
- where: src/chat/receive-loop.ts:fail, key branch
- problem: Repeated receive 401/403 responses remain invisible when the follow-up state check reports `authorized`. This violates §2.5 because receiving keeps failing despite a working access key.
- evidence: `checkState()` returns an authorized, clear-status patch, and `fail()` returns without starting the stuck timer; this can repeat indefinitely.
- fix: When disambiguation confirms an authorized instance, count the receive refusal toward the stuck timer. Test persistent receive refusal with successful authorized state checks.

## Verdict
DO NOT SHIP

Required connection and receiving-failure banners can appear late or remain absent indefinitely.
