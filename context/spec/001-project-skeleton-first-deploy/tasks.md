## Standing rules

- Run `npm ci` first in every fresh worktree (installs deps and the husky hook once Slice 2 lands).
- TypeScript is pinned to `~6.0.3`. Never install any package with `@latest`; use the ranges in tech §2.1.
- Commit messages follow Conventional Commits (CLAUDE.md → Commits); the lane brief shows the exact format. Never `--no-verify`.
- `.prettierignore` must land in the same commit as the `format:check` script (74 harness/doc files would otherwise fail the gate).
- Never edit `.claude/`, `.awos/`, `bin/`, `context/` (except ticking/ledger lines in this file by the lead), `CLAUDE.md`, `HARNESS.md`, `harness.json`, `.mcp.json`.
- Lanes never push, open PRs, merge, or change GitHub settings. Those are `[Lead]`/`[User]` steps, each with the user's OK (D3).
- Verification artifacts (screenshots, preview servers, temp clones) are deleted or stopped at the end of the Verify task that made them.
